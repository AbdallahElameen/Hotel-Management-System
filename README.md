# Hotel Management System

A simple desktop hotel management system built with Java Swing.

## Features

- User login
- Client management
- Room booking and availability
- Multiple room types
- Food and service orders
- Payment tracking
- Separate interfaces for managers, receptionists, and service staff
- File-based data storage

## Technologies

- Java
- Java Swing
- Apache Ant
- NetBeans

## How to Run

1. Clone this repository.
2. Open `G19- Phase/gui` in NetBeans.
3. Build and run the project.

Alternatively, run the included JAR file:

```bash
java -jar "G19- Phase/gui/dist/gui.jar"
